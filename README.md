# Tournament Grid (C++, Visual Studio 2022)

Консольное приложение, демонстрирующее паттерны **Composite**, **Mediator**, **Observer** на примере турнирной сетки.
Вариант 20.

**Выполнил:** [ВАШЕ ФИО], группа [Группа].

## Сборка и запуск
1. Открыть `TournamentApp.sln` в Visual Studio 2022.
2. Убедиться, что в свойствах проекта:
   - C++17 (`/std:c++17`),
   - `$(ProjectDir)` в дополнительных каталогах include,
   - `/utf-8` в дополнительных параметрах компиляции.
3. Сборка → Собрать решение (Ctrl+Shift+B).
4. Отладка → Запуск без отладки (Ctrl+F5).

## Использованные паттерны
| Паттерн | Проблема | Решение |
|---|---|---|
| **Composite** | Матч и группа матчей должны обрабатываться одинаково | Интерфейс `ITournamentNode`, реализации `MatchNode` (лист) и `TournamentGroup` (контейнер) |
| **Mediator** | Участники (судьи, команды, организаторы) не должны знать друг о друге | `TournamentSystem` — единственный посредник для всех взаимодействий |
| **Observer** | Наблюдатели должны получать уведомления без опроса | `ITournamentObserver`, регистрация в `TournamentSystem`, рассылка `TournamentEvent` |
